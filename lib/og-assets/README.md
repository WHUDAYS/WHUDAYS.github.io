# 分享预览图字体

`NotoSansSC-Medium.ttf` 仅在构建分享预览图时使用，不作为网页字体分发。

来源：[Google Fonts / Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)，许可见同目录 `OFL.txt`。
由上游 `NotoSansSC[wght].ttf` 固定 `wght=500`，并用 fonttools 保留 Unicode `0000–052F, 2000–206F, 2E80–9FFF, AC00–D7AF, F900–FAFF, FF00–FFEF` 字符范围。保留较完整的中日韩字符，新增中文标题无需重新裁剪字体。

字体和站点标志均从本地读取，构建不需要访问外部字体服务。
