# 关于本站

本站旨在对武汉大学动漫协会各种活动记录进行汇总与存档。

## 站点食用指南

1. 电脑端：**左侧栏顶部的分区菜单切换「关于、活动、部门、小群、留声箱、维护者」；下方菜单选择分区内的页面**。
2. 手机端：**点击菜单按钮展开导航，再通过分区菜单切换栏目、选择页面**。
3. 查找内容：点击**搜索**，或按 **Ctrl + K / ⌘ + K**。结果中的页面标题打开整页，下方的具体内容跳到对应位置。
