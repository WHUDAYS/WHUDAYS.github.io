# 来自Yun_me的一点碎碎念

初入漫协时正逢`QuQ`建立这个网站不久，抱着好奇的心态基本上看遍了网站的所有内容，并靠着这个网站成为了协史领域小神（自封）。随着一年来与漫协的各位相处，也算是与这个集体建立了一些感情。其间发生过各式各样大大小小的事件，或喜或忧，但总归称得上难忘的经历。

如今又进入了期末月（~~现在是6月5号下午4:09分，数字电路一章没看，破防哥好歹还就剩时序逻辑了，，，~~）,我正如本站建站时的`QuQ`一样无所事事，完全没有复习的动力。正值毕业季，看着一批老东西从此离开武大，渐渐淡出社团，我逐渐产生了完善这个网站的想法。如果说本站建站时的想法更多是站在HQ的角度去记录社团活动，那我更多地想把这个地方用来储存更多关于漫协的回忆（~~某不愿意透露姓名的小可爱丁丁亲：你协也不是什么正经协会~~）。正好我的前任外联`wweiyi`也有着相同的想法，于是在我们二人的猛烈攻势之下，网站多出了许多意义不明的神秘内容（*关注番键会谢谢喵*

学生社团是一个十分脆弱的东西，随着一代代人的毕业，一代代人的入学，曾经的传统也许会随着某个核心人物的毕业而消失，曾经的故事也许会在时间的长河中渐渐抹去；但学生社团又是个难以捉摸的东西，总有一群充满着热爱或是理想的年轻人，在（~~数据删除~~）的打压和各种各样的困难之下，依然将这个乌托邦一代代延续下去。漫协自成立以来已经经历了将近30年的光阴，这其间，尤其是前十几年的绝大多数资料都已经遗失在了时间的长河之中。但当我去整理那些侥幸幸存下来的（很多比我还大的）资料时，我依然看到了那群早已不再年轻的年轻人们，他们的热爱、他们的快乐、他们的激情，正如此时此刻的我们一般。或许跨越二十余年的光阴后，他们还会想起某时某刻在四圣兽漫画社的某个下午，留下那些青春岁月中的回忆渐渐流失的感慨；又或者三十年后（如果社团依然还能存在的话），有人会好奇于自己的父母一代人是如何在这个社团度过青春的。这个网站的存在或许就可以成为解决这些问题的契机，不仅仅能为社团的发展提供一个记录的平台，更能为现在或是未来的漫协成员们提供一个回望历史的窗口。

由于资料的来源各种各样，并且还出现了明显的断代现象，近些年的大事记采用学年来记录活动，而更早的大事记采用自然年来记录活动。在补齐中间几年的过程中，我采用了较为特殊的2020年为节点区分了新老记录方式（~~因为2019学年的2020年部分由于特殊原因没有活动~~），特此说明。
