# 2017冬日祭

- 主办：武汉大学动漫协会
- 时间：2017年11月25日（星期六）
- 地点：武汉大学桂园操场
  - 14:00~17:00 女仆咖啡厅、学园祭小游戏、社团展示
  - 18:00~21:00 动漫主题晚会
- 参与社团：
  - 武汉大学日语协会
  - 武汉大学四圣兽cosplay社
  - 武汉大学樱之音口琴社
  - 华中农业大学FOM动漫社
  - 华中师范大学三叶草动漫社
