# 恋心依旧

## 简介

> “有些鸟儿是注定不会被关在笼子里的，因为它们的每一片羽毛都闪耀着自由的光辉。”

——但如果，那只鸟的翅膀已经被折断了呢？  
——但如果，这个牢笼被冠以了“爱”和“期望”之名呢？  
一个曾经光芒万丈的天才少年，如今却困在名为“优秀”的枷锁中。  
家庭的压力、学校的规则、过往的荣光与伤痛......使得他难以呼吸。  
然而，黑暗中仍有微光：一个理解他伤痕的同桌，一名始终注视着他的女孩，以及一群同样被贴上标签的“问题学生”......  
是向世界妥协，成为众人期待的模样？  
还是赌上一切，哪怕会折断翅膀，也要撞向那堵高墙？  
你的选择将决定一切。
