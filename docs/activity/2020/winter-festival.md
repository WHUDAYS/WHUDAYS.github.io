# 2020冬日祭

- 主办：武汉大学动漫协会
- 时间：2020年11月22日（周日）
  - 10:00-16:00 梅园篮球场 庙会
  - 18:00-21:00 文理学部教五多媒体报告厅 晚会
- 地点：武汉大学梅园篮球场 武汉大学文理学部第五教学楼报告厅
- 参与社团/组织：
  - 北京大学元火动漫社
  - 武汉大学樱之音口琴社
  - 武汉大学原创音乐协会
  - 武汉大学笛萧协会
  - 华中师范大学三叶草动漫社
  - 武汉大学四圣兽Cosplay社
  - 幻光Lucas
  - 斩炎之武
