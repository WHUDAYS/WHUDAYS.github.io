# 2005 动漫知识问答游戏大会（本学年第一次集体活动）

- **时间**：2005年11月6日（星期日）19:30
- **地点**：武汉大学文理学部一区 教五 107 多媒体教室
- **主办**：四圣兽动漫协会
- **主持**：啊啊（nancyaa）、朱孔舒（整理题目并主持）

> 为让新入社的动漫爱好者展示自己对动漫的热爱、互相认识与合作而组织的本学年第一次集体活动。

## 分组方式

按社团大会上发放的纸片颜色随机分为四组（可自行调换）：

- 🟢 **青龙**（绿）
- ⚪ **白虎**（白）
- 🌸 **朱雀**（粉）
- 🟡 **玄武**（黄）

没有纸片的社员可在门口登记处领取。

## 游戏规则（五大板块）

1. **必答题**：每组答 5 道（1 道 easy、2 道 normal、2 道 hard），答对 +1，答错不加不减。答对指定题可获"炸弹"，向另一组提问一题，答对 +1、答错 −1。
2. **选答题**：在五个主题中选一个，回答其中一系列 3 道题，每题 2 分。
3. **描述题**：每组派 2 人上台，主持人举板写动漫名词，一人向被禁止看板的另一人用描述解释，限时 1 分钟，猜对一个 +1。
4. **抢答题**：2 道 easy、3 道 normal、3 道 hard、2 道 otaku，答对 +2、答错 −2。
5. **听辨 / 表演 / 模仿题**（待定）。

## 奖品

5 张海报、20 张贴纸供各组瓜分；每组均有纪念品。
