# 2007 肯德基"酷感夏日" COSPLAY 斗秀场终极 PK（武大四圣兽动漫社参演）

- **时间**：2007 年 8 月（终极 PK 于报道"前日晚"举行；2007-08-06 武汉晚报报道）
- **地点**：武汉·徐东销品茂
- **主办**：肯德基（"酷感夏日"主题活动）
- **武大四圣兽动漫社**：作为"饮誉江城"的 COSER 团体之一登台参演
- **同台团体**：九曜星盟、AngelWinds、武大四圣兽动漫社、CRAZY 联盟、灰羽联盟 等

> 报道原文：「前日晚，肯德基"酷感夏日"COSPLAY 斗秀场终极 PK 在徐东销品茂激情引爆，九曜星盟、AngelWinds、武大四圣兽动漫社、CRAZY 联盟、灰羽联盟等饮誉江城的 COSER 纷纷抖秀，成功演绎了"快乐、丰富、清新、轻松"的肯德基今夏酷感主题。……贯穿全台的新编《大话西游》轻松搞笑博得评委和观众一致掌声，勇夺"江城最酷 COSER"大奖。」

> 注：报道未注明"江城最酷 COSER"大奖具体由哪支队伍夺得（获奖节目为新编《大话西游》），故此处不臆断归属。
