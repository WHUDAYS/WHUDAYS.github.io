# 2026群名投票

- 主办：武汉大学动漫协会
- 时间：2026年6月26日-2026年7月9日
  - 6.26-7.1：群名征集
  - 7.2-7.9：群名投票
- 地点：线上

## 活动概述

群名投票是武大漫协的年度保留节目，新一届大群群名由此产生。（这里可以看[历年群名](/about/annual-group)）

群名投票分为两个主要环节：
- **征集阶段**：收集社员的群名创意
- **投票阶段**：通过投票确定最终群名

## 征集阶段规则

1. 通过发送在大群和通知群中的收集表收集结果
2. **每人只有一个提名机会**
3. 经过筛选后的提名数前十将进入最终投票（若有并列，一起入选）

## 投票阶段规则

1. 仅限正式社员投票。
2. 投票为多选，截止前不可修改或删除。
