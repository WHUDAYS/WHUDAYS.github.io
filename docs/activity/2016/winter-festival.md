# 2016冬日祭

- 主办：武汉大学动漫协会
- 时间：2016年11月12日（星期六）
  - 12:30-16:00：女仆执事咖啡厅，游戏嘉年华，社团展示
  - 18:00：冬日祭晚会
- 地点：武汉大学桂园操场
- 参与社团/组织：
  - 武汉大学日语协会
  - 武汉大学四圣兽cosplay社
  - 武汉大学笛箫协会
  - 武汉大学樱之音口琴协会
  - 华中科技大学风蓝动漫社
  - 华中农业大学fom动漫社
  - 华中师范大学四叶草动漫社
