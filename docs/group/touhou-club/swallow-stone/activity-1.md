# 武汉THO09摊位 一期活动-冬去春来

- 时间：2025年10月5日
- 地点：武汉客厅
- 参展名义：西行妖储备养料
- 首期制品：冬去春来

2025年10月5日，武汉THO09在武汉客厅举办。WHUDAYS Touhou Club 本次以同人社团"西行妖储备养料"名义在高校区域出摊，同时推出第一期制品 **冬去春来**。

本次主题以"白玉楼酒谈会"为核心故事线，借由桌上舞台讲述了幽幽子、妖梦和莉莉白在春天的一系列轶事。
